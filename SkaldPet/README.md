# Skald — Original Rune-Art Work Pet

This archive preserves the original blue-and-gold Skald design with the glowing rune artwork.

## Ready-to-use files

- `skald-sprite-sheet.png` — validated 1536×1872 ChatGPT Work pet atlas
- `skald-*.gif` — individual animation loops
- `skald-all-states.gif` — combined animated preview
- `skald-all-states.mp4` — combined video preview
- `skald-contact-sheet.png` — labeled overview of every state and frame
- `skald-validation.json` — atlas validation results

## Source artwork

The nine `source-*-clean.png` files are the transparent cleaned source strips used to assemble the final atlas. They preserve the original rune designs for future edits or reuse.

This package is separate from the currently active Work pet and does not change the active selection.
